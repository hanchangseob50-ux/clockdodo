# ClockDodo

ClockDodo is a static multilingual time-tools web app. It has no build step or package dependencies; serve this directory from the web root over HTTPS to enable the service worker and PWA features.

The main app is in `index.html` and `time-tools.html`. Shared styles live in `css/app.css`, homepage-only styles in `css/home.css`, and app behavior in `js/app.js`.
